# Languages

Translation files (`.pot`, `.po`, `.mo`) for the `ai-nathan` textdomain.

Loaded by `AiNathan\Core\ThemeSetup::setup()` via `load_theme_textdomain()`.

Regenerate the template with WP-CLI from the repository root:

```
wp i18n make-pot src/wp-content/themes/ai-nathan src/wp-content/themes/ai-nathan/languages/ai-nathan.pot --domain=ai-nathan
```
